# RBurger - Elegant Burger Builder

A fun and interactive web application for building custom burgers with a drag-and-drop interface. Create your perfect gourmet burger, view the order details, and enjoy a responsive design that works on all devices.

## Features

- **Drag & Drop Ingredients**: Easily add ingredients like beef, cheese, lettuce, tomato, and onion to your burger.
- **Visual Burger Assembly**: See your burger stack in real-time with custom images.
- **Order Summary**: Review your burger with pricing and total cost.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Elegant UI**: Modern card-based layout with gradients and smooth animations.

## Technologies Used

- **HTML5**: Structure and markup.
- **CSS3**: Styling, responsive design, and animations.
- **JavaScript**: Drag-and-drop functionality, dynamic content updates, and local storage for orders.

## How to Run

1. Clone or download the repository.
2. Ensure you have the following files in the project directory:
   - `index.html` (main page)
   - `order.html` (order summary page)
   - `style.css` (shared styles)
   - `script.js` (main logic)
   - `item.js` (ingredients data)
   - `img/` folder with ingredient images (beef.png, cheese.png, etc.)
3. Open `index.html` in your web browser (Chrome, Firefox, etc.).
4. Start building your burger by dragging ingredients from the slider to the burger area.
5. Click "ORDER" to view the summary on `order.html`.
